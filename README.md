## 🔍 Project Overview

This project explores:

- Genre distribution  
- Studio-wise production vs average rating  
- Year-wise anime release trends  
- Score patterns and outliers  
- Data cleaning and transformation techniques  

The dataset contains anime metadata such as name, studio, genre, score, release year, and more.

---

## 🧹 Data Cleaning Steps

- Removed blank rows, "Unknown" values, and `#VALUE!` errors  
- Fixed inconsistent date formats  
- Mapped release year using lookup  
- Split multiple genres into a normalized structure  
- Cleaned studio names for pivot use

## 🧠 Key Insights

- A few studios (A-1 Pictures, Madhouse, J.C.Staff) dominate production  
- Genre diversity increases significantly after 2010  
- Anime production spikes heavily between 2012–2020  
- Ratings remain stable over time despite higher output
